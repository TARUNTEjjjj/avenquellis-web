# Handwritten proof input

In the Avenquellis proof studio, a timed proof, or an official-paper response, open **Add a handwritten page**. Choose a file or use the camera picker on a supported device. The preview is local. Select **Transcribe photo** to send that page to Cloudflare Workers AI. Compare the result against the image, edit it, confirm the symbols, and choose **Add reviewed text to my answer**. Existing typed work remains ahead of the new text. Adding it triggers the ordinary draft-save behavior. Submitting the test or requesting proof review is a separate action.

A photo can contain personal details. Crop to the relevant mathematics before selection. Avenquellis sends the image pixels only to its configured transcription service after an explicit request. The application stores the text the student adds to their answer. It does not store photo files in local drafts, backups or application logs. A hosted model can misread a minus sign, exponent, inequality, line break, diagram or illegible passage. The correction step lets the student decide what to submit.

## Service and limits

The feature uses `@cf/google/gemma-4-26b-a4b-it` through the native `AI` binding and `AVENQUELLIS_HANDWRITING=enabled`. Cloudflare identifies this hosted multimodal model as supporting document OCR and handwritten text. It uses the shared Workers AI free allocation. The published rates are 9,091 neurons per million input tokens and 27,273 per million output tokens. Provider-side image encoding and actual output affect usage. The feature caps completions at 1,400 tokens; it does not measure or claim handwriting-level accuracy. [Cloudflare model release](https://developers.cloudflare.com/changelog/post/2026-04-04-gemma-4-26b-a4b-workers-ai/), [model documentation](https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/), [current model rates and free plan](https://developers.cloudflare.com/workers-ai/platform/pricing/)

- `GET /api/transcribe` reports availability and model ID without performing inference.
- `POST /api/transcribe` accepts one same-origin raw JPEG. The browser previews JPEG/PNG/static WebP sources up to 12 MiB and 24 megapixels, then rasterizes them locally to a JPEG with a 1,600-pixel maximum edge. It strips camera metadata and limits the upload to 1.5 MiB. Large, malformed and unsupported files receive an actionable error.
- The server rejects arbitrary URLs, provider prompts, unsupported MIME types, oversized payloads, nonlocal origins, invalid frame/scan structure and trailing data. Recognized JPEG APP/COM segments are removed before model inference. A photo must arrive within 10 seconds; a slower upload receives HTTP 408 with advice to check the connection or crop the page. Each address uploads one photo at a time, and an isolate reads at most eight at once. The two concurrent transcription slots are taken only after a complete photo has been read, so slow or stalled uploads never hold them. The one-minute cooldown per address starts when a photo is admitted for transcription. For IPv6, an address here means its /64 network, because one client controls every address in it; an IPv4 address counts by itself. These limits are per isolate, so they do not stop a sender that spreads over many networks; that needs a Cloudflare rate-limiting rule on `POST /api/transcribe`, which is not part of this repository. The endpoint returns noncacheable JSON; a timeout or model error produces no transcription.
- Camera capture uses a user-initiated file picker with `capture="environment"`. Availability depends on the browser and OS; the photo chooser also works on a desktop. The component does not request a continuous camera stream.
- Removing a page cancels the browser request and leaves the answer unchanged. An upload cancelled before model admission releases its upload slot without starting inference or consuming the one-minute cooldown. Cancellation after inference has begun cannot guarantee that the provider stops processing it or avoids charging its usage.
- The Pages configuration opts into `enable_request_signal` so client disconnects reach the upload handler while retaining the pinned compatibility date. [Cloudflare request cancellation](https://developers.cloudflare.com/workers/configuration/compatibility-flags/#enable-requestsignal-for-incoming-requests)

## Synthetic verification

The test fixtures are original notebook-style renderings, with a handwriting-style typeface and seeded word jitter. They are not human contestant papers or representative measures of handwriting quality. The independently authored reference text files were fixed before any model call.

1. `tests/fixtures/handwriting/synthetic-even-proof.jpg` contains a parity proof. A real `AI` binding on the initial Cloudflare integration preview returned HTTP 200 in 11.11 seconds. It transcribed all five lines, both formulas, and the conclusion. The returned text matched the reference after folding case and removing `$` delimiters. It lowercased the initial `Claim` and added math delimiters, so it was not verbatim. [Reference text](../tests/fixtures/handwriting/synthetic-reference.txt)
2. `tests/fixtures/handwriting/synthetic-gcd10-proof.jpg` exercises the bank question `number-gcd-17s23lf`. Its statement asks for `gcd(n,n + 10) = gcd(n,10)`. The sample establishes both divisor inclusions and equality of their greatest elements. The public Avenquellis site was tested with this proof on a generated RMO question with the same parameter. The student reviewed the OCR, applied corrections, completed the mock and requested a review from the report. Both model readings proposed 10/10 and the C++ checker kept the final prose mark pending. [Reference text](../tests/fixtures/handwriting/synthetic-gcd10-reference.txt)

Run `node --test tests/handwriting.test.js` for bounded image parsing, metadata stripping, same-origin admission, nonleaking errors, timeout behavior, slow and stalled uploads, quota enforcement and append-without-overwrite checks. These tests use mocked model bindings. The two fixture images stay outside `dist` and are not required by the published app.
